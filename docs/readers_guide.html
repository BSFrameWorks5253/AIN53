Quick User Guide

1. PDF Extractor 2. Event Creation 3. Folder Creator 4. Media Sorter 5. Drive Inventory

1. PDF to CSV Extractor

Extracts tables from event PDFs, maps columns, and exports them to a structured spreadsheet format.

How to Use

  1. 1
    Click on Browse PDF or drag and drop a PDF file into the upload zone.
  2. 2
    Adjust settings: Enter an optional Mauze code, or limit sequence extraction (e.g. Sticker 100 to 500).
  3. 3
    Verify column mappings. If the auto-mapper misaligns a column, adjust it via the drop-down selectors.
  4. 4
    Click Preview Data to check the formatted rows, then click Download CSV to save the final file.

2. Event Creation & Architecture

Manage Standard, QMZ, and Bethak event lifecycles, round-robin team rotation, ceremony routing, and direct folder structure generation.

How to Use

  1. 1
    Click Create New Event(s) to batch create events with deterministic sequence numbering.
  2. 2
    For Standard events, assign primary crew, camera setups, and inline sub-segments.
  3. 3
    For QMZ events, configure multi-team round-robin rotation, insert rows, or paste from Excel with standardized abbreviations (Z = Ziyafat, Q = Qadam, M = Majlis, ZO = Zafaf Olda).
  4. 4
    For Bethak events, configure ceremony segment counts with automated Misaq and Haddiyat crew rules.
  5. 5
    Click Export Folders to generate the physical directory hierarchy directly formatted for downstream Media Sorting: {TargetDir} / {Date} _{SlotCode} (e.g. 1448-06-09 _02E) containing Contributor / Cam 01, Cam 02 and leaf event directories without needing a CSV file.
  6. 6
    Optionally click Export CSV if you need an offline spreadsheet archive of the ceremony assignments.

3. CSV to Folders

Generates hierarchical directory systems automatically from your event spreadsheet to prepare target folders before sorting files.

How to Use

  1. 1
    Navigate to the CSV to Folders tab.
  2. 2
    Click Select File or drag and drop your mapping CSV file directly into the input area.
  3. 3
    Click Select Folder or drag and drop your target destination folder directly into the destination area.
  4. 4
    Click Generate Folders. Once finished, the destination folder will open automatically.

4. Media Sorting

Scans folders of raw photos and videos, analyzes files for event boundaries, maps them to sub-events visually, and performs file copies or moves.

How to Use

  1. 1
    Select the Mapping CSV File and the Root Source Directory of your files (both fields support file/folder selection dialogs as well as direct Drag & Drop).
  2. 2
    Click Start Sorting Files. The app will scan and analyze the files.
  3. 3
    Review groups in the visual dashboard. Toggle checkboxes to Edit (shift sequences of files up or down to correct group assignments) or Don't Copy (exclude items from copy/move actions).
  4. 4
    Verify your actions in the preview window, then click Copy All or Move All to run file transfers.

5. Drive Inventory

Performs verification scans across target drives to find missing numerical gaps or corrupted copy transfers.

How to Use

  1. 1
    Select the Target Drive / Folder to scan (Supports Browse or direct Drag & Drop).
  2. 2
    Click Select Location to choose where to save the generated Excel report.
  3. 3
    Click Generate Excel Report. The report is written with color-coded formatting (Red for missing files/sequence gaps, Blue for non-standard files, and Yellow for totals).
