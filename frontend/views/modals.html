1 PDF to CSV Extractor

Extracts tables from event PDFs, maps columns, and exports them to a structured spreadsheet format.

How to Use:

  • •Click on Browse PDF or drag and drop a PDF file into the upload zone.
  • •Adjust settings: Enter an optional Mauze code, or limit sequence extraction.
  • •Verify column mappings and adjust via drop-down selectors.
  • •Click Preview Data, then Download CSV.

2 Event Creation & Architecture

Manage Standard, QMZ, and Bethak event lifecycles, round-robin team rotation, ceremony routing, and direct folder structure generation.

How to Use:

  • • Click Create New Event(s) to batch create events with deterministic sequence numbering.
  • • For Standard events, assign primary crew, camera setups, and inline sub-segments.
  • • For QMZ events, configure multi-team round-robin rotation, insert rows, or paste from Excel with standardized abbreviations (Z = Ziyafat, Q = Qadam, M = Majlis, ZO = Zafaf Olda).
  • • For Bethak events, configure ceremony segment counts with automated Misaq and Haddiyat crew rules.
  • • Click Export Folders to generate the physical directory hierarchy directly formatted for downstream Media Sorting: {TargetDir} / {Date} _{SlotCode} (e.g. 1448-06-09 _02E) containing Contributor / Cam 01, Cam 02 and leaf event directories without needing a CSV file.
  • • Optionally click Export CSV if you need an offline spreadsheet archive of the ceremony assignments.
