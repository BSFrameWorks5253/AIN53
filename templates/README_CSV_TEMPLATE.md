# AIN53 Data Management - CSV Templates Specification

This folder contains standardized templates for exporting event assignments from the web portal and importing them into the **AIN53 Data Management** desktop software.

---

## 1. Primary Template: Website Export for Folder Generator
**File**: [AIN53_Website_Download_Template.csv](./AIN53_Website_Download_Template.csv)

This is the exact CSV generated by the web portal button:
> **Download File for AIN53 Data management Software**  
> *Export all assignments in this time slot as a CSV file ready for the AIN53 software.*

### Headers
`csv
Sub-Event List,Folder_Name,Contributors 1,Contributors 2,Contributors 3,Contributors 4,,Contributor's Name,Contributor's Series
`

### Column Specifications
| Column Header | Required | Description | Example Format |
| :--- | :---: | :--- | :--- |
| **Sub-Event List** | **Yes** | Full hierarchical string identifying the master date slot, sub-event, and sequence. | 1448-04-02 _01M - 01-Bilaspur-Waaz - 01-Waaz |
| **Folder_Name** | **Yes** | Target folder token used for creating physical directory structures and sorting photos/videos. | 1448-04-02 _01M-01-01Q-50427546 or 1448-04-02 _01M-01-Waaz- |
| **Contributors 1** | Optional | Primary Photographer name assigned to this sequence. | Burhanuddin H |
| **Contributors 2** | Optional | Videographer name assigned to this sequence. | Murtaza A |
| **Contributors 3** | Optional | Additional crew member (e.g., 2nd photographer / assistant). | Shabbir K |
| **Contributors 4** | Optional | Additional crew member (e.g., Drone operator). | Ali Asgar |
| *(blank)* | - | Empty column separating sequence assignments from crew directory. | |
| **Contributor's Name** | **Yes** | Unique list of all team members working in this slot. | Burhanuddin H |
| **Contributor's Series** | **Yes** | Camera series prefix (3-4 uppercase letters) for camera file auto-sorting. | BUR, MUR, SHA |

## 2. Alternate Template: Raw Route / Schedule Roster
**File**: [AIN53_Raw_Schedule_Roster_Template.csv](./AIN53_Raw_Schedule_Roster_Template.csv)

Used when importing raw route schedules directly from itinerary rosters or PDF extractions.

### Headers
`csv
Seq,Event,Sticker,Name,ITS,Location,Mobile,Mauze,Sub Event
`

## 3. Crew & Camera Series Roster Template
**Files**:
- [Crew_Camera_Series_Roster_Template.csv](./Crew_Camera_Series_Roster_Template.csv)
- [Crew_Camera_Series_Roster_Template.xlsx](./Crew_Camera_Series_Roster_Template.xlsx)

Used when importing crew members and camera series codes into the **Crew & Camera Series Roster** modal (Import File / Paste tab).

### Headers
`csv
Name,Camera Series,Role,ITS,Phone
`

### Column Specifications
| Column Header | Required | Description | Example Values |
| :--- | :---: | :--- | :--- |
| **Name** | **Yes** | Contributor Full Name | Adnan Bhai, Aliasgar Bhai |
| **Camera Series** | **Yes** | Camera prefix code used for SD card media sorting | ADN, MR_A, MUR, TAHA |
| **Role** | Optional | Contributor role (defaults to Photographer) | Photographer, Videographer, Drone, Coordinator |
| **ITS** | Optional | 8-digit ITS number | 20384721 |
| **Phone** | Optional | Mobile contact number | +919876543210 |
